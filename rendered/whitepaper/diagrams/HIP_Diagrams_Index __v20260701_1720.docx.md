HIP Diagrams Index

Purpose: tracks the seven white paper diagrams, their placement, and their status. Export each finished diagram from Design as SVG (PNG fallback), name it exactly as listed, and drop it in this folder. The number ties each file to its placement in HIP_White_Paper, so insertion later is by number, no guessing.

Naming convention: HIP_Diagram_N_Name or HIP_Chart_N_Name, matching the white paper diagram numbers.

------------------------------------------------------------
1. HIP_Diagram_1_Cascade
   Placement: Part I, the inference cascade. Also the website Architecture page.
   Content: four-tier cascade inside the operator edge trust boundary, key hierarchy anchored in gateway and phone. Passthrough crosses the boundary.
   Status: BUILT in Design. Export and drop here.

2. HIP_Diagram_2_Moat
   Placement: Part II, the moat.
   Content: concentric. Outer ring commodity (open model, router, orchestration). Defensible core: context graph, trust boundary under household key, private feedback loop.
   Status: pending.

3. HIP_Chart_3_OpenVsClosed
   Placement: Part IV, the open-vs-closed capability gap closing.
   Content: line chart, months the leading open model trails the leading closed model. ~12 months late 2024, ~3 to 4 months mid 2026. Source Epoch AI.
   Status: pending.

4. HIP_Chart_4_MemorySpread
   Placement: Part V, the memory cost spread.
   Content: horizontal bar, log scale, cost per GB. NAND/SSD ~0.27 to 0.32, commodity DDR5 ~13, server DDR5 ~40, HBM premium (not publicly priced). Source TrendForce June 2026.
   Status: pending.

5. HIP_Diagram_5_PositioningMap
   Placement: Part VI, AI compute builder positioning map.
   Content: 2x2. Axes: distance from home (horizontal), physical security to sensitive-data standard (vertical). Hyperscalers and neoclouds secure but far. Decentralized and exotic edge close or cheap but insecure. Orbital far and prototype. Top-right quadrant (secure and close) empty except cable operator edge.
   Status: pending.

6. HIP_Chart_6_LeaseBackBridge
   Placement: Part VIII, the lease-back bridge schematic.
   Content: two-band area chart over the penetration ramp. Leased capacity high early and declining, HIP household demand low early and rising, total utilization stays high. Schematic, not a forecast.
   Status: pending.

7. HIP_Chart_7_EdgeHardwareCost
   Placement: Part VII, the edge-hardware cost ladder.
   Content: horizontal bar, log scale, unit cost. Hailo kit 110, Jetson Orin Nano Super 249, Jetson AGX Thor 3499, DGX Spark 4699, RTX PRO 6000 Blackwell 13250, against a 1 GW datacenter ~60 billion. Source NVIDIA Marketplace, Orennia.
   Status: pending.
