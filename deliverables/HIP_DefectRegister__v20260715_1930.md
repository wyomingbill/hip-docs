## THE PARENT

**D-01. FAIL-OPEN ROUTING.** `intent_classifier.classify()` defaults to
`"knowledge"` on BOTH below-threshold AND embedding failure
(intent_classifier.py:190-211). `knowledge` disarms four defenses at once:
INJ-5 strips all personal facts, INJ-6 disarmed, INJ-6b disarmed, and
PERSONAL_FACT_GROUNDING_GUARD is absent from the prompt (orchestrator.py:406-407
appends it only when `intent == "personal"`). The system's default state under
uncertainty is its most dangerous state.

**Fixing D-01 collapses D-02, D-03, and D-04.** Do it first.

Evidence (2026-07-15, REQ_HARNESS harness-run): `"I take atorvastatin 20mg
every morning."` → `intent=knowledge`. A DECLARATIVE STATEMENT classified
as knowledge. This disarmed INJ-5 (strips personal facts), disarmed INJ-6
(empty-set guard not for declaratives anyway after D-15, but the intent was
wrong), and excluded PERSONAL_FACT_GROUNDING_GUARD from the prompt. The ack
was generated correctly only because the write-path ack does not use the
guard — but the intent was still wrong. G1 flagged this as a fabrication
candidate (path=generation, resolved_subjects=['maya'], no admitted facts
about maya). Fix: G1 now exempts declarative turns via delta/inj2_declarative_
override, so this specific instance no longer gates. The underlying D-01 is
untouched.

Status: NOT FIXED. Phase 3.
